# Conference Hall Booking API

REST API для автоматизації управління конференц-залами, бронюваннями, динамічного розрахунку вартості оренди та бізнес-аналітики. Проєкт реалізовано на платформі **.NET 8 (ASP.NET Core Web API)**.

---

## Технологічний стек

- **Мова та платформа**: C#, .NET 8.0 (LTS)
- **Веб-фреймворк**: ASP.NET Core Web API (Controllers)
- **ORM та БД**: Entity Framework Core 8.0, SQLite
- **Документація**: Swashbuckle Swagger UI (OpenAPI v1)

---

## Архітектура проєкту

- **Controllers/** — HTTP-маршрутизація, валідація запитів, повернення статус-кодів.
- **Services/** — бізнес-логіка (інтервальний розрахунок тарифів, перевірка перетину броней, аналітика).
- **Models/** — доменні сутності Entity Framework (`Hall`, `ServiceItem`, `Booking`).
- **DTOs/** — контракти вхідних/вихідних даних API з валідацією атрибутами.
- **Data/** — контекст БД `AppDbContext` та сидер початкових даних `DbInitializer`.

## Логіка та тарифи

Вартість оренди зали розраховується з похвилинною деталізацією залежно від часу доби:

| Інтервал | Категорія | Тариф |
| :--- | :--- | :--- |
| **06:00 – 09:00** | Ранкові години | Знижка 10% (коефіцієнт 0.90) |
| **09:00 – 18:00** | Стандартні години | Базова вартість (коефіцієнт 1.00) |
| **12:00 – 14:00** | Пікові години | Націнка 15% (коефіцієнт 1.15) |
| **18:00 – 23:00** | Вечірні години | Знижка 20% (коефіцієнт 0.80) |

Супутні послуги (проєктор, Wi-Fi, звук) тарифікуються за фіксованою ставкою на час бронювання.  
Конфлікт часу визначається за правилом: `Existing.StartTime < New.EndTime && Existing.EndTime > New.StartTime`.

## API Endpoints

### Конференц-зали (`/api/halls`)
- `POST /api/halls` — створення залу з послугами.
- `PUT /api/halls/{id}` — оновлення інформації про зал.
- `DELETE /api/halls/{id}` — видалення залу (з контролем активних броней).
- `GET /api/halls` — список усіх залів.
- `GET /api/halls/{id}` — отримання залу за ID.
- `GET /api/halls/available` — пошук доступних залів (`startTime`, `endTime`, `capacity`).

### Бронювання (`/api/bookings`)
- `POST /api/bookings` — створення броні з розрахунком вартості.
- `GET /api/bookings` — історія всіх бронювань.

### Аналітика (`/api/analytics`)
- `GET /api/analytics/summary` — зведений звіт (дохід, кількість броней, завантаженість, топ-зали та послуги).

### Через CLI:
```powershell
cd ConferenceBookingApi
dotnet run
```

Після запуску Swagger UI доступний за адресою:
`http://localhost:5259/swagger` (або порт, вказаний у консолі).
